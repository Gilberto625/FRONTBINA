Tecnologías Utilizadas

Frontend

  • Angular 17 - Framework principal
  • Angular Material - Componentes UI
  • TypeScript - Lenguaje de programación
  • RxJS - Programación reactiva
  • Firebase - Autenticación con Google

Backend

  • Django 5.2.7 - Framework web
  • Python 3.8+ - Lenguaje de programación
  • PostgreSQL - Base de datos (producción)
  • SQLite - Base de datos (desarrollo)
  • Django CORS Headers - Configuración CORS

Servicios Externos

  • SendGrid - Envío de emails OTP
  • Firebase Authentication - Login con Google
  • Render - Hosting del backend
  • Vercel - Hosting del frontend

Seguridad

  • CSRF Protection - Tokens CSRF
  • Session Management - Gestión de sesiones
  • Password Hashing - Contraseñas hasheadas
  • OTP Expiration - Códigos con expiración

Endpoints del Backend

Autenticación

  • POST /api/usuarios/register/ - Registro de usuario
  • POST /api/usuarios/login/ - Inicio de sesión
  • POST /api/usuarios/login/google/ - Login con Google
  • POST /api/usuarios/register/2fa/verificar/ - Verificar 2FA registro
  • POST /api/usuarios/login/2fa/verificar/ - Verificar 2FA login

OTP con SendGrid

  • POST /api/usuarios/verificar-otp/ - Verificar OTP registro
  • POST /api/usuarios/reenviar-otp/ - Reenviar OTP
  • POST /api/usuarios/recuperar-otp/ - Solicitar recuperación OTP
  • POST /api/usuarios/verificar-otp-recuperacion/ - Verificar OTP recuperación
  • POST /api/usuarios/reenviar-otp-recuperacion/ - Reenviar OTP recuperación
  • POST /api/usuarios/actualizar-contrasena-otp/ - Actualizar contraseña con OTP

Recuperación de Contraseña

  • POST /api/usuarios/recuperar/ - Recuperar con preguntas secretas
  • POST /api/usuarios/restablecer/ - Restablecer contraseña

Utilidades

  • GET /api/usuarios/csrf/ - Obtener token CSRF
